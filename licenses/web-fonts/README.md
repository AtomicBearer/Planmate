# Self-hosted web fonts

Original, unmodified Google Fonts assets pinned to repository revision `2eb0b48d5f760f62e286216f0859a8c540dbc1bd`. The family licenses are retained beside this file. Fonts are served locally through shared.css on all three pages. Regenerate with `pnpm run prepare:fonts`; normal installs and deployment do not download fonts.
